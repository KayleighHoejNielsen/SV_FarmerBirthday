# SV_FarmerBirthday
A Stardew Valley Mod 

This mod aims to allow the player/farmer to add a birthday of their own. This is done as an extra option on the character creation screen (only supports new files currently). 

Once the date and season is chosen and the new farm created the game will run as usually until the chosen birthday. Once the day starts on the day chosen by the player each npc will have their script changed to that of a birthday greeting.

Additions for future include: receiving a gift through the ingame mail and different birthday messages depending upon heart rating with that character.
